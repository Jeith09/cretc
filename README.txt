CRETC proposal site (sample, for proposal purposes only)

Upload this whole folder as is: index.html, media/ and samples/ must stay together.
Prices, packages and your details: edit CONFIG, FEATURES and TIERS near the top of the <script> in index.html.
Portal demo posts: edit POSTS in the same script. Paste a real Google Form link into a post's "link"
and it opens inside the pop-up instead of the sample form.
